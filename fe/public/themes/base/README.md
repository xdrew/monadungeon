# Base (Karak) theme assets

These files are generated by `tools/art` (Gemini, style bible in `tools/art/style/`), see `tools/art/README.md`.
Regenerate one with `tools/art/.venv/bin/python -m tools.art generate --only <id> --force`.
If a file is missing the UI shows the emoji from `fe/src/theme/base.js` instead (see `ThemedImage.vue`).

`lobby-bg.webp` — the title-screen background (1536×1024).
