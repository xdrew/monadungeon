# Base (Karak) theme assets

Drop the webp files listed below into these folders. Until a file exists the UI
shows the emoji from `fe/src/theme/base.js` instead (see `ThemedImage.vue`).

## monsters/

| File | Monster |
|------|---------|
| `giant_rat.webp` | Giant Rat (5 HP) |
| `giant_spider.webp` | Giant Spider (6 HP) |
| `mummy.webp` | Mummy (7 HP) |
| `skeleton_turnkey.webp` | Skeleton Turnkey (8 HP) |
| `skeleton_warrior.webp` | Skeleton Warrior (9 HP) |
| `skeleton_king.webp` | Skeleton King (10 HP) |
| `fallen.webp` | Fallen (12 HP) |
| `dragon.webp` | Dragon (15 HP, boss) |
