# Implementation Plan: Base (Karak) theme by default, Monad flavour as a build-time theme

Branch: feature/base-theme (created from feature/karak-base-rules @ 63b524d; the Karak branches are merged to main together)
Created: 2026-10-14

## Original Request
Вынести весь монадский антураж (имена и картинки монстров Molandak/Taekwonnad/Bearded Nad/Bullish/Bee/Ikan/Moyaki/Ubur, логотип Monad, фиолетовая monad-theme.css, заголовок MONADUNGEON) в отключаемую «тему» monad. Сделать основной (по умолчанию) базовую тему Karak: иконки и имена героев (Horan the Warrior и т.д.), иконки и имена монстров (Giant Rat, Giant Spider, Mummy, Skeleton Warrior, Skeleton Turnkey, Skeleton King, Fallen, Dragon). Тема monad по умолчанию выключена, но переключаема.

Follow-up answers: the theme covers the whole Monad flavour (monster names + images, Monad logo, MONADUNGEON title / page title / manifest, the purple `monad-theme.css`, the rules page, and the Monad Games ID sign-in — in the base theme the lobby has no sign-in at all). Base-theme icons are **new webp images** that the user adds himself (the plan reserves the paths and falls back to emoji until the files exist). The theme is selected **only at build time** with `VITE_THEME` (no UI toggle). Settings as for the heroes: no tests (frontend-only change, no unit runner, the e2e showcase is not touched), logging standard, docs yes, branch from `feature/karak-base-rules`.

## Settings
- Testing: no (no frontend unit runner; `fe/e2e/tests/two-player-game.spec.ts` is NOT changed — it does not reference monster names, hero icons or the Monad images)
- Logging: standard (one `console.info('[theme] active theme: <name>')` at boot in `fe/src/theme/index.js`; `ThemedImage` logs `console.warn('[theme] image missing, emoji fallback: <src>')` once per missing file)
- Docs: yes (root `README.md` + `fe/README.md` "Themes" section, `docs/DEPLOYMENT.md` build arg, `fe/.env.example`)

## Requirements Reconciliation
Authority: user request + follow-up answers (above) > current implementation (`fe/src/utils/monsterUtils.js`, `fe/src/styles/monad-theme.css`, `fe/src/views/*.vue`, `fe/src/components/**`). Backend is untouched: monster keys stay `ItemName` values (`giant_rat`, `giant_spider`, `mummy`, `skeleton_turnkey`, `skeleton_warrior`, `skeleton_king`, `fallen`, `dragon`), hero keys stay `HeroType` values (`warrior`, `thief`, `swordsman`, `warlock`, `wizard`, `oracle`), hero labels stay `HeroType::label()`.
