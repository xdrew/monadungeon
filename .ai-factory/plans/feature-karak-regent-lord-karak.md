## Requirements Reconciliation
Authority: `.ai-factory/references/karak-regent-rules.md` ("Lord Karak variant") > follow-up answers > existing implementation (`Game.php`, `Field.php`, `Player.php`, `HeroType.php`, `TurnAction.php`, `Get/Response.php`). Where the digest is silent, the decision below is the contract.

Constraints carried over: every skill check reads `Player::getHero()` (null while cursed) — 30 call sites in `Battle`, `Duel`, `Movement`, `Field`, `Player`, `Get/Response`, `Get/Action`; five PHPUnit test doubles override `getHero(): ?HeroType`; the FE shows hero actions only through `heroFlags` (no `hero === '<key>'` checks), so a merged flag set lights up every skill UI without FE logic changes; virtual players never pick a hero.
