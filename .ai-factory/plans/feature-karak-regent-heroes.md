# Implementation Plan: Karak: Regent, part 2 of 3 — the four Regent heroes

Branch: feature/karak-regent-heroes (created from feature/karak-regent-core @ e13c4af; the Karak branches are merged to main together)
Created: 2026-10-15

## Original Request
Karak Regent, часть 2 из 3 (правила в .ai-factory/references/karak-regent-rules.md): четыре героя Regent — Валдук-варвар (Берсерк, Неутомимый), барон Маркул, боевой маг (Мастер меча, Молниеносная атака), Ханна-акробатка (Метание кинжалов, Спринт), леди Лоррейн, следопыт (Медвежья атака, Подслушивание); доступны только при включённом дополнении Regent (проверка на бэкенде и фильтр regent: true в лобби), арты через tools/art. Ветка от feature/karak-regent-core.

Follow-up answers: settings as in part 1 (PHPUnit only, showcase e2e untouched; logging standard; docs yes); Valduk's healing choice is a "heal up to N" setting stored on the Player (no dialog at the turn end); Markul retreats onto an adjacent opened tile connected to the monster tile by a door (fallback: the tile he teleported from); Hanna's daggers are placed automatically (weapon slot first, then a free spell slot; the replacement dialog offers weapons and spells).

## Settings
- Testing: yes (PHPUnit only; `fe/e2e/tests/two-player-game.spec.ts` is NOT changed)
- Logging: standard (message-bus middleware logs the commands/events; no extra log statements; the art tool keeps its INFO per asset)
- Docs: yes (rules.md Heroes section, README bullet, RulesView hero entries, base-theme README rows)

## Requirements Reconciliation
Authority: `.ai-factory/references/karak-regent-rules.md` ("New heroes") > user request and follow-up answers > existing implementation (`HeroType.php`, `Battle.php`, `Player.php`, `GameTurn.php`, `TurnAction.php`, `Movement.php`, `Field.php`, `Duel.php`). Where the digest is silent, the decision below is the contract.

Constraints carried over from part 1 and the earlier heroes: every skill is a `HeroType` flag; `Player::getHero()` returns null while cursed, so reading skills through it switches them off under the Curse of Karak; virtual players never pick a hero (the lobby adds the AI without one), so active skills are human-only and the AI needs no logic; duels are two `Battle`s, so every combat skill implemented in `Battle`/`Player` applies in a Battle Arena duel automatically.
